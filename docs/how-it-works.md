# How it works

How Lectern works, as built: the pages in the repository's
[`docs/`](https://github.com/matasarei/lectern/tree/main/docs) folder.

- [Projects, sessions and files](concepts.md): project folders, Overview and tabs, where
  files come from, the app's data, first run.
- [The chat](agent.md): the agent loop and its tools, the system prompt, the script sandbox
  and the coding model, context and compaction, making pictures, reading replies aloud,
  follow-ups, web search.
- [OCR sessions and Documents](ocr.md): the phases, page notes, review, the Document format,
  exports.
- [Models and memory](models.md): roles, hardware tiers, the catalog, languages, voices,
  downloads, runners, image models, fitting a model, leases and swapping.
- [Architecture](architecture.md): the processes, the code map, the stack, the databases,
  the module contract, the CLI and settings, installing.
- [Code map](code-map.md): lookup tables of modules, large-file landmarks, HTTP/WebSocket
  routes, agent tools, database tables and frontend screens.
- [Security design](security.md): each threat and its defence. Reporting a vulnerability:
  [SECURITY.md](https://github.com/matasarei/lectern/blob/main/SECURITY.md).
- [Acceptance runs](https://github.com/matasarei/lectern/tree/main/docs/acceptance): what
  was tested on which machine, milestone by milestone.

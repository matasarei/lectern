# Lectern

Lectern is an AI workbench that runs on your own computer. You work in **projects**: folders
of chats, OCR sessions and the files they produce. Every model runs on your own machine, so
what you type and import stays on it. The internet is for downloading the models, and for web
search once an admin switches it on.

To install it, follow the README for
[Linux](https://github.com/matasarei/lectern#install-on-a-linux-server),
[a Mac](https://github.com/matasarei/lectern#install-on-a-mac) or
[Windows](https://github.com/matasarei/lectern#install-on-windows).

## Using Lectern
